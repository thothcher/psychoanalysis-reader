# ფსიქოანალიზის რიდერი

სიღრმის ფსიქოლოგიის სასწავლო აპლიკაცია: ავტორების მოკლე შეჯამებები, შედარების ცხრილები, ბარათები, დაკავშირების, მეხსიერების და თანმიმდევრობის თამაშები და ქვიზი.

A single-page study app for a Georgian depth-psychology course reader (Freud, Adler, Jung, Anna Freud, Erikson, Klein, Winnicott, Kernberg, Horney, Fromm and more).

Open `index.html` in a browser, or use the hosted version on GitHub Pages.
